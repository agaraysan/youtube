quiz-uploader

A private upload tool for one creator's own quiz channel

quiz-uploader is an internal tool used by a single individual creator. It publishes the creator's own original quiz and brain-teaser videos (matchstick puzzles, riddles, spot-the-difference and kanji quizzes) to the creator's own YouTube channel.

What it does

  • Uploads finished videos to the owner's own channel (YouTube Data API: videos.insert).
  • Sets the title, description, tags, thumbnail and scheduled publish time (videos.insert, thumbnails.set).
  • Changes the privacy status of the owner's own videos (videos.list, videos.update).
  • Records which channel the owner's token belongs to (channels.list, mine=true).

Who can use it

Only the channel owner. The tool runs in the owner's private GitHub repository on GitHub Actions. It has no public sign-up, is not distributed or sold, and never accesses any other user's channel or data.

Data

See the Privacy Policy. This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service.
